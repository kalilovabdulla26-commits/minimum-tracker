# Минимум — трекер + Жевшен + Тасбихат

Сайт: https://minimum-tracker.vercel.app

## Маалымат кайда сакталат
«Минимум — жооптор» Google таблицасынын **Жооптор** барагында.
Тиркеме ар бир адам + күн үчүн бир сап жазат (U, V мамычалары — тиркеменин белгилери).
Форманын жооптору да ошол эле баракта, тиркеме аларды да окуп, рейтингге кошот.

- `apps-script/Code.gs` — таблицадагы Apps Script (Расширения → Apps Script).
- `config.js` — `SHEET_API` = Apps Script веб-тиркемесинин шилтемеси.

## Апта
Жума дүйшөмбүдөн башталат (таблицадагыдай). % — 13 иш боюнча орточо.

## Кирүү (логин + сырсөз)
Логин — аты + үйү. Ар ким биринчи киргенде өзүнө сырсөз коёт.
Сырсөздөр таблицанын **Колдонуучулар** барагында (шифрленген хэш түрүндө) сакталат.
Сырсөзүн унутса — ошол адамдын сабын **толук өчүрүңүз**, ал кайра жаңы сырсөз коёт.
Сырсөзсүз башка адамдын ордуна белги коюу мүмкүн эмес (таблица өзү текшерет).
